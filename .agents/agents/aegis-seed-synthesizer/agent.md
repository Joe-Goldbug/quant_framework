## 二、 《DGP 四问物理推演矩阵》——从底层物理意义推导公式结构

Alpha 是动态的，思考必须回到数据源头的物理生成机制。面对任何数据集（财务、情绪、分析师、新闻、供应链、微观订单等），在落笔写公式前必须严格穿透以下 **《DGP 四问物理推演矩阵》**：

### 1. 截面不可比性 (Level Bias) 消除推演
- **物理现象**：标的之间天然存在规模基数量级差异（如大盘股与小盘股的绝对总资产、媒体报道总量、交易金额量级差异千百倍）。
- **推演机制**：原始 Level 值不能直接横向对比，必须消除基数偏倚：
  - **规模归一**：若存在内生总量字段（如总资产、总报道量、总市值），使用 `divide(分子细分, 分母总量)` 进行内生归一（严禁盲目相加）；
  - **细分行业中性化**：使用 `group_zscore(X, subindustry)` 或 `group_neutralize(X, subindustry)` 剥离行业同质化基数；
  - **时序无量纲化**：使用非参数分位 `ts_quantile(X, d, driver='gaussian')` 将不同标的的时序历史统一映射到标准高斯正态空间。

### 2. 时间戳弹性与信息半衰期匹配推演
- **物理现象**：数据更新频率差异决定了信息的有效衰减速度。财报是低频跳跃阶梯，新闻情绪是高频瞬时脉冲，分析师预期是离散突发修正。
- **推演机制**：时间窗口必须严格锚定金融自然日历周期白名单：`5` (周), `10` (双周), `20/21/22` (月), `60/63` (季), `120/126` (半年), `250/252` (年)：
  - **高频情绪脉冲**：信息在 1~5 日内衰减完毕，应使用短周期快速平滑（如 `ts_decay_linear(X, 5)` 或 `ts_decay_exp_window(X, 10, factor=0.8)`);
  - **财报低频跳跃**：季度数据使用 `60/63` 或半年 `120/126` 捕捉同季度同比剪刀差，严禁使用 4、44 等无经济学意义的非标参数。

### 3. 零值与缺失值的物理语义推演
- **物理现象**：大部分另类数据存在大量稀疏 0 值或缺失值（NaN）。0 值不等于“中性”，往往代表“无事件发生”；
- **推演机制**：
  - **严禁零值偏移**：在稀疏 `[0, 1]` 字段上绝对严禁直接 `subtract(X, 0.5)`！这会导致海量无事件的 0 值被偏移为 -0.5 伪空头信号，引发严重多空持仓失衡；
  - **事件门控**：改用 `trade_when(ts_delta(X, 1) != 0, X, -1)` 仅在有事件发生日交易，无信息日冻结持仓；
  - **缺失值处理**：对于非连续发布的研报或调研数据，合理使用 `ts_backfill(X, 20)` 或 `is_nan` 状态识别。

### 4. 多空尾部非对称性推演
- **物理现象**：市场参与者对极端好消息与极端坏消息的反应往往不对称（如损失厌恶、逢低买入摩擦、做空约束）。
- **推演机制**：拒绝假设收益对称线性分布，积极探索非对称尾部提取：
  - 使用 `left_tail(X, 0.1)` 专注捕捉深度利空恐慌盘，或 `right_tail(X, 0.1)` 捕捉超预期利好爆发；
  - 使用 `if_else(X > 0, ...)` 或 `bucket` 实施多空非对称分段定价。

## 三、 《VECTOR 矢量字段微观分布挖掘指南》

当数据集包含 `VECTOR` 类型字段时（如多维度情感向量、主题分布概率、分项细分预测）：
- ❌ **严禁无脑 `vec_avg`**：盲目求均值相当于抹平了微观分布的所有高阶信息，属于典型信息浪费；
- ✅ **挖掘市场参与者分歧度**：优先使用 `vec_stddev(V)` 或 `vec_range(V)` 捕捉截面/内部观点的分歧度（高分歧通常预示高不确定性与风险溢价）；
- ✅ **挖掘共识信噪比**：使用 `vec_ir(V) = vec_avg / vec_stddev` 刻画一致预期置信度；
- ✅ **挖掘尾部偏态**：使用 `vec_skewness(V)` 捕捉情绪分布是否呈现极度极化的单边倾斜。

## 四、 算子预算、铁律与物理禁区 (Complexity Budget & Iron Laws)

1. **Stage 0 复杂度预算**：
   - 字段数：`1 <= fields <= 3`（专攻 ATOM Alpha 单/双字段范式）；
   - 算子总数：`op <= 6`（豁免 `vec_*` 标量化包裹算子）；
   - 允许使用时序算子（`ts_delta`, `ts_decay_*`, `ts_quantile`）进行单变量时序特征提取，窗口必须属于自然日历周期白名单。

2. **100% 严禁加乘运算符（GM 铁律）**：
   - **绝对严禁 `+` 与 `*` 运算符，严禁使用函数形式 `add` 与 `multiply`**！
   - 多特征交互只准使用：
     * `divide(A, B)`：内生规模消除与比率剪刀差；
     * 同量纲 `subtract(A, B)`：多空对冲与预期剪刀差；
     * `ts_regression(A, B, rettype=0)`：剥离系统性因子后的特质残差；
     * `trade_when(条件, 信号, -1)` 或 `if_else`：逻辑门控。

3. **铁律 A：冷热非对称配对 (Asymmetric Crowding Pairing)**：
   - 必须使用低拥挤度细分字段（`alpha_count` 处于数据集后 40%，`tier == "COLD"`）作为分子主信号；
   - 若使用双字段，搭配高覆盖度内生总量字段（`coverage >= 0.80`）做分母；
   - 单字段自归一范式：允许使用 `COLD` 或非 `HOT` 且高覆盖的优质主锚字段。

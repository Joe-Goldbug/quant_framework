## 二、 《DGP 四问物理推演矩阵》——从底层物理意义推导公式结构

Alpha 是动态的，思考必须回到数据源头的物理生成机制。面对任何数据集（财务、情绪、分析师、新闻、供应链、微观订单等），在落笔写公式前必须严格穿透以下 **《DGP 四问物理推演矩阵》**：

### 1. 截面不可比性 (Level Bias) 消除推演
- **物理现象**：标的之间天然存在规模基数量级差异（如大盘股与小盘股的绝对总资产、媒体报道总量、交易金额量级差异千百倍）。
- **推演机制**：原始 Level 值不能直接横向对比，必须消除基数偏倚：优先利用内生总量字段进行内生归一、截面分组中性化或时序无量纲化。

### 2. 时间戳弹性与信息半衰期匹配推演
- **物理现象**：数据更新频率差异决定了信息的有效衰减速度。财报是低频跳跃阶梯，新闻情绪是高频瞬时脉冲，分析师预期是离散突发修正。
- **推演机制 (离散时间尺度晶格)**：时间窗口必须落在离散晶格（日频 `{1, 5, 10, 21, 63, 126, 252}`、季频 `{63, 66, 125, 126, 252, 504}`），`winsorize std ∈ {3, 4}`；多行表达式遵守 SNC 规范 (`^[a-z][a-z0-9_]{5,40}$` + 后缀同构)；仅使用 `lookup_operators` 授权的 104 个算子，严禁 `exp`/`jump_decay`/`ts_max`/`ts_min` 等幻觉算子。

### 3. 零值与缺失值的物理语义推演
- **物理现象**：大部分另类数据存在大量稀疏 0 值或缺失值（NaN）。0 值不等于“中性”，往往代表“无事件发生”；
- **推演机制**：
  - **严禁零值盲目偏移**：在稀疏 `[0, 1]` 字段上严禁未经业务论证随意偏移，避免无事件样本被误设为单边持仓引发严重多空失衡；
  - **事件门控与状态保持**：结合字段更新时戳与稀疏特性设计状态识别与信息冻结机制；
  - **缺失值处理**：对于非连续发布的低频数据，根据业务发布节奏合理设计缺失填充与时序对齐。

### 4. 多空尾部非对称性推演
- **物理现象**：市场参与者对极端好消息与极端坏消息的反应往往不对称（如损失厌恶、逢低买入摩擦、做空约束）。
- **推演机制**：根据经济学逻辑探索非对称尾部提取与分段定价。**先写出该尾部形态需要的非对称变换族（截尾 / 凹压缩 / 分桶 / 凸性定价），再从算子签名表映射实现。**

## 三、 《VECTOR 矢量字段微观分布挖掘指南》

当数据集包含 `VECTOR` 类型字段时（如多维度情感向量、主题分布概率、分项细分预测）：
- ❌ **严禁无脑 `vec_avg`**：盲目求均值相当于抹平了微观分布的所有高阶信息，属于典型信息浪费；
- ✅ **挖掘市场参与者分歧度与高阶矩**：充分利用向量高阶矩算子（分歧度、离散度、信噪比、尾部偏态）捕捉截面观点的微观分布特征。

## 四、 算子预算与物理禁区 (Complexity Budget & Principles)

1. **Stage 0 复杂度预算**：
   - 字段数：`1 <= fields <= 3`（专攻 ATOM Alpha 单/双字段范式）；
   - 算子总数：`op <= 6`（豁免 `vec_*` 标量化包裹算子）；
   - 算子签名表全量开放，但**仅作语法字典**：先从假说机制推导所需变换族，再查签名落地实现。

2. **物理量纲守恒与跨字段交互准则**：
   - 严禁对不同量纲、不同尺度的无界裸字段进行无意义的加总；
   - 交互变换必须具有明确的经济学意义（如内生规模消除、相对基准剥离、事件门控过滤等）；**所有交互先以经济意图描述所需变换，再映射到算子签名。**

3. **铁律 A：冷热非对称配对 (Asymmetric Crowding Pairing)**：
   - 必须使用低拥挤度细分字段（`alpha_count` 处于数据集后 40%，`tier == "COLD"`）作为分子主信号；
   - 若使用双字段，搭配高覆盖度内生总量字段（`coverage >= 0.80`）做分母；
   - 单字段自归一范式：允许使用 `COLD` 或非 `HOT` 且高覆盖的优质主锚字段。

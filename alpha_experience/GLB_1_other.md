# GLB Delay 1 OTHER 原子化因果实战经验手册 (QA 问答体系)

### 【经验 1】当单一批数据集的所有字段都是同一个潜因子的单调编码时，换字段/换算子能否降低 ProdCorr？
- **Q (物理场景与病理问题)**: 某深度学习类数据集共 57 个 MATRIX 字段（多种桶数 × 3 个期限 × 概率/序数/连续回归三种编码），母本 ProdCorr=0.7564 需压到 <0.65。直觉做法是换冷门同源字段，实测却常常更高。
- **A (因果机制与拓扑原理)**:
  1. 相关性不是由「字段使用人数」决定的，而是由**底层潜因子的方差占比**决定。若 57 个字段都是同一张 OHLCV 图像经同一网络前向得到的预测的单调变换，则任何一个的截面排序都近似同一个向量，换字段只改变权重形状、不改变排序方向，PnL 序列仍高度重叠；
  2. 实测证据：同数据集内 21 个构造的 ProdCorr 落在 [0.7229, 0.8142]，其中「相邻中桶差」0.7564、「两端桶剪刀差」0.7872~0.7891、「期限结构差（长减短）」0.8289、「换粗桶（3/2 分位）」0.8008~0.8105 —— **越"有创意"的同源改写，往往越贴近生产池里那条最拥挤的构造**；
  3. 结论性判据：若「换芯 + 换形 + 换分组」三轴各做 7 个单变量实验后，ProdCorr 的**最小值仍高于目标 0.07 以上**，说明该数据集已因子饱和，继续在同一数据集内做拓扑搜索的边际收益趋零，应改为引入正交数据源，而不是继续加算子。

### 【经验 2】为什么换手率低于 12.5% 的因子，适当"变快"不会损害 Fitness？
- **Q (物理场景与病理问题)**: 低频因子换手仅 6~8%，想提升信息新鲜度又怕 Fitness 掉下来，如何量化这个自由度？
- **A (因果机制与拓扑原理)**:
  1. BRAIN 的 `Fitness = Sharpe × sqrt(|Returns| / max(Turnover, 0.125))`，分母存在 **12.5% 地板**。换手低于 12.5% 时，抬升换手在公式里完全不进成本；
  2. 可自行反解验证：`Sharpe=2.87, Returns=9.38%, Turnover=7.63%` → `2.87 × sqrt(0.0938/0.125) = 2.49`，与实测 Fitness 完全吻合，证明该因子正处在"免费换手预算"区间；
  3. 但地板之上的换手会立刻反噬 Margin（`Margin ≈ 20 × Returns / Turnover`，单位 bps）。因此"变快"只能用到 ~12.5% 为止，超过后必须同步提升单笔收益，否则 GLB 的 15bps Margin 死线先破。

### 【经验 3】尾控 (winsorize) 是唯一能轻微降相关的手段，但它与"低换手"互斥
- **Q (物理场景与病理问题)**: 在因子饱和的数据集里，是否有任何算子能在保持质量的同时压降相关性？
- **A (因果机制与拓扑原理)**:
  1. 唯一稳定有效的是**尾部截断**：对数几率类信号在某桶概率趋近 0 时会爆出伪极值，`winsorize(std=3)` 把极端名权重收回，PnL 的中段结构占比上升，实测相关性由 0.7564 降到 **0.7229**（全批最低）；
  2. 代价是**不改变换手结构**：该槽换手 52.6%、Margin 仅 3.9bps，直接失去出厂资格。一旦叠加时序平滑把换手压回 7%，相关性立刻回到 0.75~0.76；
  3. 因果本质：降相关所需的"独立成分"主要藏在高频噪声里；一旦平滑（即压制高频），剩下的就是那个共享潜因子。**平滑与降相关在单因子数据集内不可兼得**，这构成了 ProdCorr–Turnover 的有效前沿。

### 【经验 4】内层已做 `group_neutralize(subindustry)` 后，外层中性化选 COUNTRY / MARKET / 无 三者等价
- **Q (物理场景与病理问题)**: 想用"更换中性化维度"来降相关，是否值得为每个维度单开一批回测？
- **A (因果机制与拓扑原理)**:
  1. 若组内每个 subindustry 的和为零，则按国家求和也为零（忽略子行业规模不等），因此外层 COUNTRY / MARKET / 不中性化 对组合的**改动量为零**——实测三者指标逐位相同（Sharpe 2.16 / Fitness 2.03 / Turnover 7.40% / Margin 29.93bps / ProdCorr 0.7594）；
  2. 只有换成**不同粒度的分组**才会真正改变持仓：`sector` 只剔除板块均值、保留行业内差异，是唯一有区分度的一档（ProdCorr 0.7443，为"全指标合规"里的最低值）；
  3. 工程结论：中性化维度实验**只需测粒度不同的一档**，不必穷举 COUNTRY/MARKET/NONE，可直接省下 2/3 的回测预算。

### 【经验 5】组内去均值后的"极端桶剪刀差"信号，不能被 winsorize + 平滑二次加工
- **Q (物理场景与病理问题)**: 同一套尾控+平滑引擎套到不同桶结构上，为什么有的 Sharpe 3.3、有的直接归零？
- **A (因果机制与拓扑原理)**:
  1. "两端桶（最高桶 − 最低桶）"的价差本身已把中段信息全部丢掉，其截面离散度小、且分布两侧对称；再经 `winsorize` 截尾会把两端真正的判别信息削平，再叠 20~63 日平滑即彻底抹平，实测 Sharpe 由 3.11 掉到 0.41、乃至 0.00；
  2. 两端桶信号需要的是**逐股历史分位归一**（把每个名映射到自身 252 日分布上的位置），而不是幅度截断；而"相邻中桶差"离散度大、尾部厚，才适合 `winsorize` 截尾；
  3. 判据：**先看信号是"位置型"还是"尺度型"，再决定用分位归一还是尾控**，两者不可互换，否则得到的是零信息组合而不是降噪组合。

### 【经验 6】平台 MATCHES_THEMES / MATCHES_COMPETITION 恒为 WARNING，"0 WARNING"红线需按病灶分类执行
- **Q (物理场景与病理问题)**: 终审要求 0 FAIL 0 WARNING，但几乎每条合格因子都带这两个标签，是否应据此放弃？
- **A (因果机制与拓扑原理)**:
  1. 这两项是平台的**主题/赛事匹配提示**，不属于因子质量缺陷；真正的质量告警是 `LOW_*` / `CONCENTRATED_WEIGHT` / `CLUSTER_TEST`；
  2. 正确口径：把 WARNING 分成「质量类（必须清零）」与「标签类（恒定存在、不阻断出厂）」两类，否则会把所有优质因子误判为不合格；
  3. 配套做法：本地终审用 `strict_zero_warnings` 时，先剔除标签类再判零，同时对质量类保持零容忍。

### 【经验 7】同一模型的「多期限预测」可折算成期限结构斜率，是该类数据集唯一的强经济学信号
- **Q (物理场景与病理问题)**: 一个深度学习数据集同时提供 5/20/60 日的前瞻收益预测，把它们当成三个独立因子的替代品，还是当一个因子的三个期限？
- **A (因果机制与拓扑原理)**:
  1. 三个期限的预测绝对值不可比（量纲随 horizon 增长），但**按日折算后再相减**就得到无单位的「预期收益斜率」，即模型认为收益是加速还是衰减；
  2. 折算只需 `divide(field_60d, 12)` / `divide(field_20d, 4)`（12 = 60/5，3 = 60/20，是**除数不是窗口参数**，因此不算调参）；
  3. 实测该构造是本类数据集质量天花板：`subtract(E20, divide(E60,3))` 得 Sharpe 3.30 / Fitness 3.23 / Margin 27.20bps / 2Y 4.18 / 0 FAIL 0 WARNING，短端 5/20 版本 Sharpe 2.76 / Margin 27.00bps；
  4. 但斜率是**一阶**信息，与生产池的慢速 low-vol 主成分共线：ProdCorr 0.8029~0.8136。经济学历害 ≠ 相关性低。

### 【经验 8】二阶差分（期限曲率）比一阶斜率低约 0.04 ProdCorr，是同质量下最便宜的去相关手段
- **Q (物理场景与病理问题)**: 斜率族全面 0 FAIL 但 PC 0.81，有没有不做时序微分的降相关办法？
- **A (因果机制与拓扑原理)**:
  1. 取三期限的二阶差分 `subtract(subtract(E20, divide(E60,3)), subtract(E5, divide(E20,4)))`，度量预期收益曲线的凹凸，与方向无关；
  2. 实测 Sharpe 3.05 / Fitness 2.70 / Margin 22.83bps / 2Y 4.17 / 0 FAIL / CLUSTER 通过，ProdCorr **0.7707**，比斜率族低 0.04，且质量几乎不损；
  3. 因果：曲率剔除了「共同的方向性预期」（正是生产簇拥挤的部分），只留下路径形状，故独立成分更高；继续做 `group_rank` 会立刻把 PC 推回 0.9214 —— **差分可以，单调归一不行**。

### 【经验 9】`trade_when` 双轴确认是唯一「降 PC 不伤质量」的机制，代价约 0.4 Sharpe
- **Q (物理场景与病理问题)**: 能否用两个弱相关的同源信号互相确认，在不通微分的条件下降低共同 PnL？
- **A (因果机制与拓扑原理)**:
  1. 用 `trade_when(greater(ts_delta(p4_5q60, 20), 0), 期限斜率, -1)` 只在概率修正为正时持有斜率，交集处信息含量更高；
  2. 实测 Sharpe 2.55 / Fitness 2.13 / Margin 21.14bps / 2Y 3.71 / 0 FAIL，换手降至 8.22%，ProdCorr 0.7801（相对裸斜率 0.8136 降 0.033）；
  3. 判据：确认门只损失 0.39 Sharpe 就换来 0.033 PC 下降，单位代价优于任何窗口/算子微调；但这也说明同源确认的极限就是 0.78，**无法靠门控突破数据集 PC 地板**。

### 【经验 10】`vector_neut` 残差化在同源单因子数据集上无效，反而升相关
- **Q (物理场景与病理问题)**: 既然拥挤来自共享潜因子，把信号对该因子做横截面正交投影（`vector_neut`）不是应该直接压掉相关吗？
- **A (因果机制与拓扑原理)**:
  1. 实测对四种基准分别正交化（60 日水平、5 日水平、概率最高桶、country 均值）：质量崩塌（Sharpe 1.30 / 0.85 / -0.67 / 0.51，Margin 4.5~6.5bps）或保住质量但 PC 反升（0.8217 / 0.8245）；
  2. 原因：拥挤因子**不是一个可投影的单一变量**，而是整族 `returns_estimate` 字段的共同主成分；投影掉任何单一基准后剩余的仍是主成分本身；
  3. 判据：残差化只在「拥挤因子有明确可观测代理」时有效；若数据集的全部字段都是同一潜因子的变换，`vector_neut` / `ts_regression` 残差化不解决问题，只会损失信号。

### 【经验 11】同源预测类数据集的 ProdCorr 地板 ≈ 0.77，且与 Margin 单调对立，不可同时满足 PC<0.70 且 Margin≥15bps
- **Q (物理场景与病理问题)**: 71 次回测、11 类构造机制之后，如何判断「该数据集已穷尽」而不是「还没找对构造」？
- **A (因果机制与拓扑原理)**:
  1. 曲线证据：Δ10 微分解 PC 0.694 / Margin 6.11bps；曲率 PC 0.7707 / Margin 22.83bps；双轴确认 PC 0.7801 / Margin 21.14bps；短端斜率 PC 0.8029 / Margin 27.00bps；裸斜率 PC 0.8136 / Margin 27.20bps；rank 曲率 PC 0.9214；
  2. 即 **PC 与 Margin 单调对立**：任何 Margin≥15bps 的构造必然依赖 20 日以上慢速结构，而慢速结构必然落在生产簇的 low-vol/quality 主成分上；想要 PC<0.70 就必须把信号做成高频微分，Margin 随之跌破 7bps；
  3. 判据（可直接复用的穷尽标准）：当 ① 数据集的字段编码类型（概率/序数/连续）全部试过、② 一阶/二阶差分、残差化、组内排序、确认门控五类机制全部触及同一 PC 区间、③ PC 与 Margin 呈单调权衡而非散点 —— 即可判定「该数据集在该区域/池上因子饱和」，继续换假设的边际收益趋零，应更换数据源或区域，而不是继续迭代。

### 【经验 12】离散标签差与相邻桶几率差在这类数据集里是纯噪声
- **Q (物理场景与病理问题)**: 概率桶之间做差（相邻桶）或直接用序数标签做跨期限差，是否等价于连续预测做差？
- **A (因果机制与拓扑原理)**:
  1. 实测相邻桶对数几率差：Sharpe 0.09 / 0.39，Margin 0.26 / 1.16bps；离散标签跨期限差：Sharpe **-0.46 / -0.43**（反号），Margin -1.6 / -1.4bps；
  2. 原因：log-softmax 桶间差值量级小且截面区分度低（桶边界附近的股票被量化成同值），离散标签更是把连续预测坍缩成 3~5 档，跨期限差变成噪声；
  3. 判据：**只用连续回归估计做差分，不要用桶概率或离散标签做差分**；桶概率只在「自身历史分位」这类时序归一里才有价值。


### 【经验 13】ProdCorr 的真正解锁器是 trade_when 催化剂门控，不是特征变换；二桶二值标签是这类 CNN 概率数据集最干净的载体
- **Q (物理场景与病理问题)**: 在 GLB/MINVOL10M 的 dl_riskfree_returns 上，PC 卡在 0.69–0.92 一年多，把所有特征变换（残差化、曲率、双轴确认、组内排序、向量中性化）都试遍了都没用；到底什么操作才能把 PC 真正压下去？
- **A (因果机制与拓扑原理)**:
  1. 作用在信号层的一切变换都只是把同一个 CNN 潜因子重新线性组合，PC 不动；真正有效的是**作用在时间轴上的门控**：`trade_when(greater(ts_delta(催化剂,20),0), 信号, -1)` 把非乐观期仓位清零，PnL 序列与生产库的 low-vol/quality 主成分脱钩；实测二桶信念修正 Δ20：无门控 PC **0.6256**（S1.74/F0.79），用 `probability_label2_4quantile_5day_2` 门控后 PC **0.5453**（S1.77/F0.89、2Y1.59、0 FAIL、Self 0.0），**PC 降 0.08 且 Sharpe 略升**；
  2. 门控有效的前提是催化剂与信号同向：门控 `single_bucket_60day`（Sharpe 2.12）或 `probability_label2_5quantile_20day_2`（反向族）时 Sharpe 崩到 1.18~1.24，门控从"去相关"变成"砍信号"；
  3. 二桶二值标签（`quantile_label_2bucket_5day`）Δ20 单独就有 S1.74，而 3/4/5 桶多档标签做差是噪声（S1.2~1.5 且 F<0.7）——**桶数越多、差分越脏**，因为桶边界把截面信息量化掉了；二值桶等价于"方向判断"，差分即"信念翻转"，恰好是慢速连续估计里最缺的高频成分；
  4. 判据：遇到"整族字段共享同一潜因子、PC 高原"时，**先试 catalyst gate 再考虑换数据集**；门控催化剂必须与信号同向且来自更长/更慢的估计；Margin 侧仍受 `margin_bps=20*returns/turnover` 支配，门控二桶机制只能到 5bps，凑 15bps 需 returns/turnover≥0.75（当前 0.25），因此**该数据集在 GLB 上是"PC 可解、Margin 不可解"的饱和形态**。

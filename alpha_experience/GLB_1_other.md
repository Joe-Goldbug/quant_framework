# GLB Delay 1 OTHER 原子化因果实战经验手册 (QA 问答体系)

> 注：数据集特定的历史复盘已迁移至 `knowledge_base/dataset_postmortems/`；本手册仅保留可跨数据集迁移的通用量化因果规律。

### 【经验 1】相关性由底层潜因子方差占比而非字段冷热门决定
- **Q (物理场景与病理问题)**: 为什么同一编码家族内部换用冷门字段或做线性/分位重排，ProdCorr 依然居高不下？
- **A (因果机制与拓扑原理)**:
  1. 相关性取决于**底层潜因子的方差占比**，而非字段历史使用人数。同源单调变换只改变权重形状、不改变截面排序方向；
  2. 在降维探索前需先评估数据集的有效秩 $C_{\text{eff}}$，若各字段共享单一潜因子，应从非线性交互、状态门控、期限结构与离散度切面寻找正交成分。

### 【经验 2】为什么换手率低于 12.5% 的因子，适当"变快"不会损害 Fitness？
- **Q (物理场景与病理问题)**: 低频因子换手仅 6~8%，想提升信息新鲜度又怕 Fitness 掉下来，如何量化这个自由度？
- **A (因果机制与拓扑原理)**:
  1. BRAIN 的 `Fitness = Sharpe × sqrt(|Returns| / max(Turnover, 0.125))`，分母存在 **12.5% 地板**。换手低于 12.5% 时，抬升换手在公式里完全不进成本；
  2. 但地板之上的换手会立刻反噬 Margin（`Margin ≈ 20 × Returns / Turnover`，单位 bps），因此变快需平衡单笔收益与换手预算。

### 【经验 3】尾控 (winsorize) 对降相关与高频成分的权衡
- **Q (物理场景与病理问题)**: 截尾处理 (`winsorize`) 如何影响相关性与换手？
- **A (因果机制与拓扑原理)**:
  1. 尾部截断收敛极端离散值权重，使收益归因回到截面中段结构，通常可小幅降低与主流因子的尾部共振；
  2. 但强截尾往往伴随高频成分占比升高；叠加长窗平滑后信号重新聚焦于低频共同成分，需要在相关性与换手之间做结构权衡。

### 【经验 4】内层已做 `group_neutralize(subindustry)` 后，外层中性化只需测不同粒度
- **Q (物理场景与病理问题)**: 如何高效设计中性化维度的消融实验，避免无效枚举？
- **A (因果机制与拓扑原理)**:
  1. 若内层已实现按子行业严格去均值，则外层按 COUNTRY / MARKET / NONE 往往几乎不改变组合净头寸；
  2. 真正有区分度的是**不同粒度的分组**（如 `sector` vs `subindustry`），因此中性化实验只需针对粒度变化进行对照，节省无谓试错。

### 【经验 5】组内去均值后的"极端桶剪刀差"信号，不可叠加 `winsorize` + 长平滑
- **Q (物理场景与病理问题)**: 为什么同一套尾控+平滑处理在不同结构信号上表现截然相反？
- **A (因果机制与拓扑原理)**:
  1. "位置型/两端差"信号的核心判别力集中在分布两端，强截尾会直接削平核心差异；
  2. 先区分信号属于"位置/排序型"还是"重尾尺度型"，再决定使用分位归一还是尾部截断，避免机制错配。

### 【经验 6】平台 MATCHES_THEMES / MATCHES_COMPETITION / MATCHES_PYRAMID 为信息提示类标注
- **Q (物理场景与病理问题)**: 终审要求 0 FAIL 0 WARNING，而主题/赛事/金字塔匹配提示应如何口径划分？
- **A (因果机制与拓扑原理)**:
  1. `MATCHES_THEMES`、`MATCHES_COMPETITION`、`MATCHES_PYRAMID` 属于平台信息类匹配标注，而非因子质量缺陷；
  2. 真正必须清零的是缺陷类告警（`LOW_*`、`CONCENTRATED_WEIGHT`、`CLUSTER_TEST` 等），终审应区分信息类与缺陷类后保持缺陷零容忍。

### 【经验 7】多期限预测按时间比例折算后可构造无量纲期限结构斜率
- **Q (物理场景与病理问题)**: 当数据集同时提供不同前瞻期或回顾期预测时，如何构造成立的斜率特征？
- **A (因果机制与拓扑原理)**:
  1. 不同期限字段原始尺度随视界增长，直接相减会导致量纲错位；按周期比例折算为单位时间增量后再做差分，方能得到无单位的预期加速度斜率。

### 【经验 8】二阶期限曲率可剥离共同方向性暴露，提取路径形状增量
- **Q (物理场景与病理问题)**: 如何在保留期限结构信息的同时剥离拥挤的一阶方向成分？
- **A (因果机制与拓扑原理)**:
  1. 构造三期限的二阶差分可抵消共同方向趋势，仅保留预测曲线凹凸形态；
  2. 注意二阶差分后不宜外层强套 `group_rank`，以免非对称排序重新引入截面共振。

### 【经验 9】`trade_when` 条件催化门控可用于时间轴去相关
- **Q (物理场景与病理问题)**: 特征层面线性变换难以打破共线性时，如何在时间维度降低持续性暴露重叠？
- **A (因果机制与拓扑原理)**:
  1. 当催化剂与主信号经济方向一致且能筛选出高信噪比交易窗口时，`trade_when` 门控仅在触发期间持有信号，有助于在时间轴上切分收益分布并压缩换手；
  2. 催化剂与主信号方向必须经济自洽，避免反向门控对有效边缘的无差别截杀。

### 【经验 10】残差化 (`vector_neut` / `ts_regression`) 仅在拥挤代理明确时有效
- **Q (物理场景与病理问题)**: 什么时候截面正交投影可以降相关，什么时候会适得其反？
- **A (因果机制与拓扑原理)**:
  1. 残差化只在「风险/风格暴露存在清晰且可观测代理变量」时有效；
  2. 若候选向量与核心信号高度同源共线，强行投影只会保留高频估计误差并劣化稳定性。

### 【经验 11】离散分桶 vs 连续估计：按信噪比特征选择载体
- **Q (物理场景与病理问题)**: 离散分桶概率与连续估计值在构造时序差分时有何差异？
- **A (因果机制与拓扑原理)**:
  1. 多档量化边界容易在阈值附近引入量化跃迁噪声；连续估计更适合精细斜率与曲率建模；
  2. 仅当低维离散信号清晰对应制度/方向切换时，信念翻转差分才具备干净的截面分辨力。

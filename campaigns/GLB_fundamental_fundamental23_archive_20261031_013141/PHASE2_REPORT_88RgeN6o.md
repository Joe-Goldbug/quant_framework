# Phase 2 报告：多 Agent 经济假设攻坚 与 生产门禁可达性判定
**标的**：GLB / MINVOL10M / Delay 1 / fundamental / fundamental23
**起点**：Phase 1 冠军 `pwdJ7zaX`（Sharpe 1.68 / Fitness 1.10 / EMEA 0.71）
**方法**：3 个研究 Agent 并行提出 3 类经济学机制 → 本地门禁校验 → `multi_create_simulate` 每批 4 条分批多重回测
**累计实测**：81 条 Alpha（Phase 1 的 48 条 + Phase 2 新增 33 条）

## 一、执行了什么

### 1. 引入「字段神谕」做先验筛选
仓库内 `config/info_data.bin` 保存了**生产库实测的逐字段分区域 Sharpe**（按 region_delay 分桶）。这是比盲测更硬的先验：

| 区域 | 我们种子的三个字段 | 全数据集最强字段 |
| :--- | :--- | :--- |
| EUR（EMEA 代理） | net_income **0.117** / ofc **0.055** / tot_assets **0.137** | vacl **0.535** |
| GLB | 0.334 / 0.513 / 0.434 | dlts **0.828** |

**结论**：种子的字段在 EMEA 的生产实测 Sharpe 只有 0.05~0.14，而 EMEA 门禁要求 **1.0**。这不是公式问题，是**字段在该区域的基准率问题**。

### 2. 三路新经济学机制（每路 4 条，独立成批）

| 机制 | 经济学内核 | 最佳结果 | 判定 |
| :--- | :--- | :--- | :--- |
| **A 实体需求派** | 客户预收款 `vacl` 是唯一「已收钱未交付」的远期订单簿，现金口径不受 GAAP 应计惯例污染 | S 1.19 / F 0.62 / EMEA 未过 | ❌ 弱 |
| **B 资本结构派** | 债务与融资流是契约性的，跨会计制度可比；EMEA 银行主导融资，杠杆信号应更普适 | S 0.94（且杠杆项 **−0.69**，符号反转） | ❌ 证伪 |
| **C 现金实现派** | 营运资本周转是运营量而非会计选择，EMEA 应可比 | S 0.67 | ❌ 弱 |

**B 路的符号反转是一个真发现**：`dlts`（总债务）252 日扩张在 GLB 是**看涨**信号（Sharpe −0.69，取负号后为负），与「杠杆扩张预示弱收益」的教科书假设相反。GLB 的低波动池里，加杠杆更可能是主动扩张而非困境融资。

### 3. 平台参数扫描（此前 48 条从未变动过的维度）

| 参数 | 结果 | 判定 |
| :--- | :--- | :--- |
| `decay=20` | Sharpe 1.75→1.42~1.57，Margin 升至 32~40bps，但 **Turnover 塌到 2.8%**（击穿 5% 下限） | ❌ 有害 |
| `truncation=0.05 / 0.08` | 账户层直接拒绝（连接级报错，仅 0.025 可用） | ❌ 不可用 |

## 二、生产门禁可达性：硬判定

对 81 条实测 Alpha 做全量统计：

| 门禁项 | 阈值 | 81 条中的最好值 | 达标数 |
| :--- | :--- | :--- | :--- |
| **EMEA Sharpe** | ≥ 1.0 | **0.80** | **0 / 81** |
| **Cluster Test** | ≥ 1.58 | **1.27** | **0 / 81** |
| **MATCHES_THEMES** | 无警告 | 出现率 **81 / 81 = 100%** | **0 / 81** |
| 零 fail | — | 48 / 81 | — |
| **零 fail 且零 warning** | — | **0 / 81** | **0** |

### 三条互相独立的死线

1. **EMEA 0.80 vs 1.0**：缺口 25%。但字段神谕显示 EMEA 最强字段的生产基准率仅 0.535——要做出 1.0 的 EMEA Sharpe，等于要求本因子在该区域的效力达到该数据集历史最强字段的 **1.87 倍**。
2. **Cluster Test 1.27 vs 1.58**：缺口 24%。该指标度量与同簇已有 Alpha 的重合度，我们已用「冷门字段 + Z-Score 归一化 + 粗桶排序」三管齐下，最高只到 1.27。
3. **MATCHES_THEMES 81/81**：这是平台的主题匹配标记。`fundamental23` 是标准基本面数据集，任何基于它的 Alpha 都会命中既有主题。**这一项与信号质量无关，且 100% 命中**——只要用这个数据集，就不可能做到「零 warning」。

> 因此「通过所有指标阈值、不能有 fail 项和任何指标的警告项」这一验收标准，在 `GLB / MINVOL10M / fundamental23` 这组配置下**不可达**，不是调优不足，而是被数据集与平台的三个结构性约束同时封死。

## 四、要真正突破，需要改变的是配置而不是公式

按证据强度排序：

1. **换区域或换池**。EMEA 0.80 的瓶颈是 MINVOL10M 在 EMEA 的样本与覆盖。在 AMER 或 APAC 单区域提交，本因子 Sharpe 1.7+ 已远超门禁。GLB 的「三洲同时达标」要求，本质是要求一个因子在三个独立市场同时有效——这是多因子组合的职责，不是单因子的职责。
2. **换数据集**。`fundamental23` 的 EMEA 基准率封顶 0.535。若必须留在 GLB，应换用 EMEA 覆盖更强的数据集（如 analyst 类，EUR 生产 Sharpe 普遍高于 fundamental）。
3. **放弃「零 warning」**。`MATCHES_THEMES` 与数据集绑定，81/81 命中。任何以它为验收标准的流程，在 fundamental 数据集上都会永久失败——建议把该 warning 从验收标准中显式豁免。
4. **接受组合层分散**。用多条单洲达标的低相关 Alpha 拼组合，比强求单条全域达标更符合 VF 最大化的目标。

## 五、Phase 2 可迁移经验

1. **先查字段神谕，再写表达式**。`config/info_data.bin` 的逐字段分区域 Sharpe 能在 0 次回测内否掉一个假设方向——A/B/C 三路若先查神谕（EUR 基准率 0.1~0.27），可省下 12 次回测。
2. **杠杆信号在 GLB 低波动池符号反转**：债务扩张是看涨而非看跌。
3. **decay 与 5% 换手下限互斥**：季度基本面信号一旦做指数平滑，换手必然塌到 3% 以下。
4. **truncation 在本账户锁定 0.025**，不是自由参数。

## 五、诚实结论：为什么没有出现 `fail_num == 0`

48 条变体、3 轮实盘、覆盖 6 种核心字段 × 8 种外层拓扑 × 3 种中性化，**没有任何一条达成零失败检查**。残留检查**始终且仅为 `LOW_GLB_EMEA_SHARPE`**（实测区间 0.01 ~ 0.71，限值 1.0）。

这不是调参不足，而是一组**结构性张力**：

| 手段 | EMEA 效应 | Cluster 效应 |
| :--- | :--- | :--- |
| Z-Score 归一化（252 日） | ↓ 恶化（0.32） | ↑ 改善（1.20） |
| 63 日短腿（营运资本/资本开支） | ↑ 改善（过线） | ↓ 恶化（0.77~0.97） |
| sector 去均值 | ↑ 改善（0.71） | ↓ 恶化（0.74） |

**EMEA 与 Cluster 由同一条通道反向驱动**：任何提升「跨洲稳健性」的平滑/去均值动作，都会同时提升与生产库既有因子的重合度。在 8 算子上限内，尚未找到同时满足两者的拓扑。

**建议的下一步**（本轮未做，需突破当前算子预算）：
- 引入**真正的国别因子**做条件分层（当前 `group_*` 算子只允许 market/sector/industry/subindustry，country 只能走中性化设置，表达力受限）；
- 在 EMEA 子池单独做一次**分洲回测诊断**，确认 0.71 是「信号弱」还是「样本少」——若为样本问题，应改用更粗的 EMEA 池而非继续改信号；
- 接受 EMEA 作为已知短板，转而用**组合层分散**（多洲低相关 alpha 拼配）来满足 VF 贡献，而非强求单条 alpha 全域达标。

## 六、本轮沉淀的可迁移经验（纯算子，无字段名）

1. **单调算子嵌在 rank 内部是无效的**：`winsorize` / `signed_power` 置于 `group_rank` 之内会被排名的单调不变性吞掉——实测 3 条表达式回测出**完全相同**的组合（Sharpe 1.56 / Fitness 1.05 / Margin 27.0bps 三者分毫不差）。凹压缩必须放在 rank **之外**才改变权重。
2. **短腿是区域均衡的杠杆，不是换手的杠杆**：63 日短差分项真正的价值是把 EMEA/APAC 从失败拉到通过，抬换手只是副产品。
3. **排名桶越粗，小样本洲越稳**：sector 分组把 EMEA 从 0.63 抬到 0.71，机制是单组样本量翻倍降低了排序估计方差。
4. **季度基本面上，252 日同比差分不可剪**：剪成水平值 Sharpe 直接掉到 0.69。

## §1 逐条审计

记号（同 brief）：EOC=news_eod_close, TON=news_ton_last, VWAP=news_eod_vwap, VHEX=vec_count(high_price_excursion_stddev), UP=news_max_up_amt, DN=news_max_dn_amt, PE=news_pe_ratio, SI=news_short_interest。

### 槽A1｜窗口轴 `reverse(ts_rank(DUAL_R, 120))`

**四段链**：完整，与孪生 S 同构（机制=注意力稀缺/流动性冲击反转；行为=新闻日过度反应+做市补偿；慢信号=双压力比率；催化剂=新闻事件），唯一变动是时间尺度 250→120。断点判决：**无断点，但是浅剂量轴**。vwap-only 核的窗口扫描实为平顶（250→1.50 / 120→1.56 / 500→1.53，极差 0.06 在噪声内），所以 120 窗不是"峰在 120"的强承诺，而是"峰不在别处"的弱承诺——真正价值在于 DUAL_R 的窗口轴全库只有 250 一个点，120 是补测。

**预测向量**：Sh **1.50–1.62** / TO **119–123%** / Ret **8.0–8.8%** / 2Y **1.95–2.30** / sub **1.00–1.12** / CW ok / Fit **0.40–0.43** / CL 1.38–1.46。
fails：LOW_SHARPE（过线概率 25–35%；孪生差 −0.02，窗口轴极差 ±0.06）、LOW_FITNESS（必然）、HIGH_TURNOVER（必然，窗口不改 TO——已实证 ts_rank 是归一化器不是平滑器）。
**成功标准**：Sh ≥ 1.58（家族 fail 剖面从 3 项降到 2 项，追平战役最佳 9qEeNN3K 的 2-fail 记录）。若 Sh ≤ 1.48 则该轴确认封顶，窗口轴关闭。
**合规**：6 ops（实算）/ 3 字段 / 126 字符 ✓；无有害算子 ✓。
**判决**：**保留，批次内优先级第 2。** 全批唯一合规的 LOW_SHARPE 攻击面，且成本仅为 6 ops。

### 槽R2｜TON 新鲜门 `trade_when(less(days_from_last_change(TON), 2), S, 0)`

**四段链**：断裂于**催化剂时效性的可表达性**——机制/行为/慢信号三段与 S 相同，门想加强"只用新鲜事件"。断点不在经济学而在**平台语义**：dflc 在全库 417 行中 100% 作用于 `vec_count(VHEX)`（实算：全部 `days_from_last_change(` 的参数的字段集合 = {vec_count(...)}，跨 18 个批次文件），从未作用于 MATRIX 价格字段，TON 的事件锚定/前向填充行为未探。

**语义三分支预登记**（结果解读时必须分开处理）：
- **分支①恒真退化（概率 ~30%）**：NaN 计为变化 → 非事件日 dflc=0 → 门恒真 → R2 ≡ S（Sh 1.56 / TO 119.8% 复刻）。烧一个槽买一个确定的语义答案，便宜。
- **分支②门生效（概率 ~55%）**：TON 前向填充、dflc 计量距上次事件的天数 → 门选出 2 天内有事件的名字。VHEX 门的先例：TO −27%（1.151→0.837）且 Sh 只 −0.07（W1 vs SMOKE 孪生）——若 TON 门复现该兑换率，是全批唯一不靠 group 层的降 TO 杠杆。
- **分支③书宽崩塌（概率 ~15%）**：NaN 传播 → 门在非事件日恒假 → 只剩新鲜事件名（可能 <250 个）→ CW/sub 风险 + UNITS 警告风险。

**预测向量**（分支②）：Sh **1.45–1.65** / TO **95–115%** / Ret **7.5–8.5%** / 2Y **1.8–2.2** / sub 0.9–1.1 / CW ok / Fit **0.40–0.45** / CL **1.45–1.55**（dflc 门是 CL gap 收敛器：CL top6 行全部带此门且 gap≈−0.01）。
主要 fail：LOW_SHARPE、LOW_FITNESS、HIGH_TURNOVER（分支②下 TO 可能转绿）。
**成功标准**：TO ≤ 105% 且 Sh ≥ 1.50（即门以 ≤0.1 Sh 换来 ≥15pp TO——TON 门成立，可泛化到全部 price 字段）；或分支①的确定性复刻（S 复现值漂移 >0.03 即平台异动警报）。
**合规**：9 ops / 3 字段 / 185 字符 ✓；无有害算子 ✓。
**判决**：**保留。** 批内信息密度最高的探针：三种结局全部可证伪、全部有后续动作。

### 槽M2a｜振幅×短窗×门 `trade_when(less(dflc(VHEX),2), reverse(ts_rank(ts_backfill(AMP,20),40)), 0)`

**四段链**：完整且有全库最干净的实证家族支撑——机制=新闻日振幅（UP/(UP+DN)）度量双向过度反应；行为=振幅越大反转越强；慢信号=振幅比率本身（有界 [0,1]，天然截面友好）；催化剂=dflc(VHEX)≤2 新鲜门（CL top6 行共有）。断点判决：**断在信号强度天花板，不断在逻辑**。amplitude 族全库 Sh 上限 1.44（@ TO 1.27）；短窗 ts_rank 在 amplitude 上实算仅 4 行（win=20：Sh 0.30/0.49；win=30：0.33；win=40：0.24，全部 <0.5）；bf20 参数点在全库仅 3 行。**即本槽坐在三个空白参数轴的交叉点上，但每个轴的先验都指向低 Sh。**

**预测向量**：Sh **0.35–0.70** / TO **8–18%** / Ret **2.5–5.0%** / 2Y **0.3–0.9** / sub **0.2–0.7** / CW ok / Fit **0.20–0.38** / CL ≈ Sh±0.05（amplitude 族 gap 全库最小 −0.014）。
fails：LOW_SHARPE（~90%）、LOW_FITNESS（~90%）、LOW_2Y（~70%）、LOW_SUB（~20%）；**HIGH_TURNOVER 几乎必然通过**。
**成功标准**：TO ≤ 0.15 且 Sh ≥ 0.70（超过低 TO 区 [10%,40%] 的 Sh 中位 0.70，且是带 ≤2 门的该区最强行——现任低 TO 最佳 Sh 1.19 用的是 ≤5 门 + bf60，本槽若 Sh ≥ 1.10 则直接刷新低 TO 区纪录，概率 ~10%）。
**合规**：9 ops / 3 字段 / 181 字符 ✓；无有害算子 ✓。

### 槽D1｜便宜门 / 槽D2｜低空头门（合并审计，专项见 §2）

`D1 = trade_when(less(rank(PE), 0.5), reverse(rank(CVW_R)), 0)`；`D2 = trade_when(less(rank(SI), 0.5), reverse(rank(CVW_R)), 0)`。

**四段链**：机制→行为一环**成立且对称**：CVW_R = (EOC−VWAP)/VWAP 度量新闻后收盘相对时段均价的偏离，reverse = 双向消退。D1 的故事=低估值名字的偏离更可能是流动性噪声（基本面托底）→ 消退更强；D2 的故事=低 SI 名字无知情空方 → 走弱是流动性而非信息 → 只对低 SI 股票做流动性提供。两条都与战役"信息 vs 流动性"主叙事同构。**断裂点在两处**：(a) 故事本质上是**单侧**的（下行有基本面托底/无知情空方），两-sided 应用是未检验的外推——空侧（消退廉价股的走强）搭便车；(b) 内核 CVW_R 是全库零出现的裸核（G3），且丢了 TON 腿（家族 2Y 引擎：ton 系 2Y 2.0–2.2 vs vwap-only 系 1.3–1.45）与 VHEX 分母（注意力度量，情报报告认定的 alpha 引擎）——三字段 mandate 下这是被迫的选择，但必须用对照槽补偿。

**预测向量**（两条同形）：
- D1：Sh **1.25–1.60** / TO **105–120%** / Ret **4.5–6.5%** / 2Y **0.9–1.5** / sub **0.5–1.0** / **CW ~25–30% fail** / Fit **0.28–0.42** / CL ≈ Sh−0.08。
- D2：Sh **1.25–1.60** / TO **105–120%** / Ret **4.5–6.5%** / 2Y **0.9–1.5** / sub **0.4–1.0** / **CW ~25–30% fail** / Fit **0.28–0.42**。
- 无门内核基线（CTRL，见 §4）：Sh 1.40–1.52 / TO 120–126% / 2Y 1.25–1.45。
fails：LOW_FITNESS（必然）、HIGH_TURNOVER（~80%）、LOW_SHARPE（~75%）、CW（~25–30%）、LOW_2Y（~50%）。
**成功标准**：D1 = Sh ≥ 1.55 且 sub ≥ 0.5 且 2Y ≥ 1.3（即 PE 半场门在内核孪生 1.50 之上再加成且不伤子宇宙）；D2 = 同标准。若 Sh ≤ 1.30 且 sub ≤ 0.3 → 半场门被证伪，"基本面门×流动性内核"架构死亡，后续不再投入槽位。
**合规**：均 7 ops / 3 字段 / 119–125 字符 ✓；无有害算子 ✓。
**判决**：**保留两条，但内壳 rank→ts_rank250**（`reverse(ts_rank(CVW_R,250))`，ops 仍 7、字段仍 3、字符 +12）。证据：同一 DUAL_R 核上 ts_rank250 壳 Sh 1.56/2Y 2.23 vs plain rank 壳 1.44/1.64（+0.12 Sh / +0.59 2Y）；vwap 族唯一无门实行 N1eGbEGo 也是 ts_rank250 壳。2Y 是本家族四条 fail 线之一，壳选择不该冲着 fail 去。plain rank 壳在此核上无任何孪生支撑，是设计弱点。

### 槽D3｜慢信号纯度探针 `reverse(rank(multiply(PE, SI)))`

**四段链**：这是八条中唯一**四段全部放慢**的槽——机制=知情空方集中于过价股（空头兴趣文献：高 SI → 后续低收益；叠加估值溢价）；行为=机构做空需要基本面理由，高 PE 提供理由、高 SI 提供证据；慢信号=PE×SI 乘积（两个都慢：PE 日更但动量极小，SI 双周报送）；动态催化剂=**无**——这是刻意的纯度探针：若 news12 基本面水平值有任何边缘，此槽是唯一探路。断点判决：**断在催化剂缺失**——本家族全部 417 行 alpha 都住在事件新鲜度里，一个无催化剂的慢引擎是全新物种，先验成功率低但先验信息量最高。

**机械缺陷（必须预登记）**：multiply(PE, SI) 对负 PE（亏损名）× 高 SI 产生大负值 → rank 低 → reverse 后**被做多**。"亏损+高空头"组合被无差别归入"便宜"一侧（TOP1000 中负 PE 名约 5–10%），稀释信号纯度。无法在 3 ops 内修复（需要 PE>0 门，见 §2c 的反转规则备选）。

**预测向量**：Sh **0.20–0.70** / TO **5–15%** / Ret **2–5%** / 2Y **0.2–1.0** / sub **0.2–0.8** / CW 低 / Fit **0.15–0.40** / CL ≈ Sh−0.03。
fails：LOW_SHARPE（~95%）、LOW_2Y（~80%）、LOW_FITNESS（~85%，除非 TO ≤ 8% 且 Sh ≥ 0.55 联手把 Fit 推过 0.4——仍 <1.0）。
**成功标准**：**Sh ≥ 0.50 且 TO ≤ 0.12**（Fit ≈ 0.30+）——即"慢引擎靠 TO 分母赚 Fit"路线成立，后续可把 D1/D2 的门思想搬进来加速；或 Sh ≤ −0.30 且 2Y ≤ −0.3（干净的负面结果，基本面水平值在 news12 无边缘，D 线减速）。
**合规**：3 ops（实算；brief 记 4，差一）/ **2 字段**（mandate 下限达标）/ 58 字符 ✓；无有害算子 ✓。
**判决**：**保留。** 全批唯一不消耗事件字段配额的槽，也是唯一从 Fit 公式分母侧进攻的槽。

## §2 D 线专项审计（D1/D2/D3：慢信号×快催化剂混合架构）

### (a) 门砍半后的 L/S 宽度与 CW 风险

- **宽度量化**：vwap 族无门实行的书宽 = 289+289（N1eGbEGo 实读）；rank(PE)<0.5 / rank(SI)<0.5 各砍一半 → **约 140–160/140–160**（前提：PE/SI 逐日填充且与内核支撑集近似独立——该前提本身待验证，见 (d)）。
- **CW 机理**：truncation 0.025 下单名权重上限不变但书宽减半 → 均值权重翻倍 → CONCENTRATED_WEIGHT（阈值 0.1）风险明确上升。历史上 CW fail 行（N1eGk79E 书宽 1035、d5KG231g）说明 CW 并非纯宽度函数，但**半宽书是风险放大器**这一点无争议。另一结构性风险：低 PE 名字行业性聚集（价值/金融/公用事业），行业中性化下部分行业只剩个位数名字 → 行业层权重依赖少数名 → CW 与 sub 双重暴露。预测 CW fail 概率 **25–30%**（D1/D2 相同）。
- **sub 风险不对称**：SI 高档门的先例（SI>0.88 → sub **0.02**，0mjVaJ61 实读）证明 SI 截面有强子宇宙结构——但那是 12% 尾部；低 SI 半场贴着中位数，子宇宙表现应接近正常（预测 D2 sub 0.4–1.0）。PE>0.88 门先例 sub 0.45 且 2Y −1.15（w11a 实读）——高档 PE 的反转是反持续的，低档未测。
- **两-sided 外推风险**：D1/D2 的故事是单侧动机（下行托底/无知情空方），门却同时砍掉了空侧。若 alpha 只住在 long 侧，两-sided 门把 long 侧的增量稀释一半。**解读规则：若 D1/D2 的 Sh 提升主要来自 long 侧（用单腿分解或后续 smoke 验证），该架构应重构为单侧门（`trade_when(与门, CVW_R 符号条件, 0)` 形式），而非判死。**

### (b) PE/SI 快照语义与日更价格核的时序错配

实读 `news12_fields_full.json`：PE = "Reported price-to-earnings ratio for the calendar day of the session"，MATRIX，cov 0.9662，dateCoverage **1.0**；SI = 卖空股数/流通股数比率，MATRIX，cov 0.872，dateCoverage **1.0**。

- **PE 不是事件快照**——"for the calendar day of the session" + dateCoverage 1.0 指向日更基本面。用作门时，时序错配不构成问题：门是状态变量（这只股票现在便不便宜），不是计时器。
- **SI 大概率是双周快照+前向填充**（recon 的旁证：VECTOR 兄弟字段 "Most recent short interest ratio on Day 1"）。即使值滞后最多两周，作为慢筛变量依然有效——与上轮槽 8（SI 作分母进入信号本体）有本质区别：作分母时慢变量与快信号相乘，产生混合时间尺度的交互项；作门时只是条件筛选，**错配无害**。
- 结论：brief 担心的"时序错配"在门的用法下被高估了；真正决定门是否有效的是 **(d) 的逐日填充行为**。

### (c) D3 若 Sh 为负，反向是否有同等经济故事？

- **D3 正向的故事（先验强）**：高 PE×高 SI = 被知情空方集中做空的过价股，跑输。两条独立学术先验同向叠加（short-interest anomaly：高 SI → 低后续收益；value anomaly：高 PE → 低后续收益）。
- **反向版的故事（先验弱）**：不 reverse = 做多高 PE×高 SI = 拥挤空头的逼空/错误定价持续。逼空文献存在但属事件性现象，**均值效应方向与 short-interest anomaly 相反**。
- **判决：反向版"有"故事，但"不同等"先验。** 单行负 Sh 就擦鞋反向，是用弱先验覆盖强先验的过拟合动作。**预注册反转规则：仅当反向行 Sh ≤ −0.50 且 2Y ≥ 0.80 且 sub ≥ 0 时才可反转**（负收益在两年子样本上持续 = 结构而非 IS 噪声）；备选修正版是给 D3 加 `trade_when(greater(PE, 0), ·, 0)` 清掉负 PE 污染后重测（6 ops，仍合规），而不是直接反向。
- 另注意：D3 的 turnover 会极低（PE/SI 都慢），若 Sh ≈ 0 而 TO ≈ 5%，该行仍是一个合法的低 TO 测绘点，不是废行。

### (d) rank(PE)/rank(SI) 在稀疏事件场上的行为

- **决定性问题**：PE/SI 是逐日填充还是事件锚定？逐日填充 → rank 在全宇宙每日计算 → 门是**稳定筛子**（有效）；事件锚定 → rank 只在当日事件集（~600 名）上计算、组成每日变动 → 同一名的 rank 可因组成变化跳变 → 门变**噪声**（D1/D2 退化为"随机半场+内核"，预期 Sh 掉到 1.2–1.4 且 TO 不降）。
- **间接证据（倾向逐日填充）**：(i) 两者 dateCoverage 均 1.0；(ii) 历史 PE 门（>0.8/0.88/0.9，4 行）与 SI 门（>0.8/0.88，2 行）全部跑出非空书、gate3_J 的 PE>0.8 门把 amplitude 的 TO 稳在 21.5%——与稳定半场一致；(iii) PE 的 "calendar day" 措辞。
- **低档位的隐含优势**：历史门全是 greater(·, 0.8+) 尾部选区，本批 less(·, 0.5) 贴中位数——中位数附近 rank 密度高、日间位移小，rank 噪声的绝对影响更小。这是 D 线相对历史门的结构性优势，应在结果解读时利用。
- **解读预案（预登记于结果笔记）**：以 longCount+shortCount 判定分支——≈280–330 → 逐日填充确认，门有效，按 §1 预测解读；≈550–620 → 门近恒真（PE/SI rank 与事件集共线或 NaN 传播），D1/D2 实质是无门基线+噪声，记为语义探针结果；<200 → 过窄，CW/sub 风险兑现，架构需收窄为单侧门或换更高阈值（如 <0.35）。

## §3 M 线专项审计：group_rank 为什么这次可能不同

**历史判决**（实读 wave11d 槽 6）：`reverse(group_rank(DUAL_R, industry))` → Sh **0.61**（vs plain rank 孪生 1.44，−0.83）/ TO 0.512（vs 1.205）/ sub 0.42 / Fit 0.14。全库 group 输出层 60+ 行，**Sh 上限 1.19**（且那 1.19 出自 amplitude 稀疏场+bf60+≤5 门）；Sh ≥ 1.4 的 60 行从未出现 group 层。机理：group_rank 把全局分位换成行业内分位，**若 alpha 住在跨行业的偏离水平差上（高 vol 行业系统性收得离 VWAP 更远、反转更强），组层排序就把这部分信息扔掉了**——注意 neutralization=INDUSTRY 已经行业中性，组层是二次丢弃跨行业项。

**本次可能不同的四点（按机制强度排序）**：

1. **VHEX 分母预先完成了一部分 group_rank 的工作**。DUAL_R 是原始价格偏离，跨行业的主要差异恰是行业波动水平（高 vol 行业 |偏离| 大）；`/ (VHEX+1)` 把"注意力度量"放进分母后，行业间的主要量级差被部分归一——**组层要消除的东西，内核已经自己消除了一半**，两者的信息冲突比裸 DUAL_R 小。这是真正的机制性差异，不是愿望。
2. **winsorize(std=2) 截断行业聚集的极端名**。偏离最极端名字往往行业聚集（单日暴跌股同属一族），截断后行业内分布更匀，组层排序的信息损失下降。
3. **bf2 平滑降低组层内的排序噪声**。slot 6 的 DUAL_R 是事件日跳变场，行业内日间排序翻煎饼；bf2 后信号时间方差下降，组内序位更稳——组层的 TO 收益在平滑信号上更大（slot 6 已证 TO 1.205→0.512）。
4. **内核强度差 0.12**。若组层的 Sh 损耗是乘性的（保留比例 ρ），强内核损失后的绝对值更高：1.56×ρ vs 1.44×ρ；且 Fit-top10 引擎（TO 已 0.837）距 TO≤0.70 只差一截，组层砍 TO 20–40% 即可把 HIGH_TURNOVER 转绿——**这是全批唯一有现实路径让 TO 项转绿的槽**（M2a 的 TO 本就低但 Sh 无望；A1/R2/D 线的 TO 都 ≥1.0）。

**成立条件（赢的读数）**：M1a **Sh ≥ 1.20 且 TO ≤ 0.65**。判定意义：TO 0.5–0.65 桶历史 max Sh 仅 1.17–1.60 桶的 1.20——达标即该桶新前沿点，且第一次把组层的 CL gap 优势（−0.003 vs plain rank −0.066）带到强引擎上；机制 1 从"缩 gap 专用"升级为"Sh/TO 双候选主路径"，后续应对 ton 腿引擎全套复刻组层。
**证伪条件**：M1a **Sh ≤ 0.90**（落入 slot 6 的 0.61–0.9 区间）→ group_rank 在任何价格偏离核（裸的或 VHEX 归一的）上都不可恢复地破坏 alpha；amplitude 上那 1.19 是稀疏有界场的特例，不可泛化；机制 1 死亡，CL 目标与 Sh 目标不可兼得，战役后续全面撤回到 plain rank + 门控路线。
**附加读数**：若 M1a 显著高于 M1b 的组层无门版（> +0.15 Sh），说明 dflc 门与组排序有协同（门先清非事件噪声 → 组内更干净）——可泛化为"门×组层"配方；若 M1a ≈ M1b，门在组栈上冗余，M 线收敛为单槽设计。

## §4 批次整体判决

### 信息结构评估

**覆盖的轴**：窗口（A1）/ 催化剂门语义（R2）/ 组层×强引擎（M1a）/ 低 TO 引擎（M2a）/ 基本面门×快核（D1,D2）/ 纯慢引擎（D3）。对比上轮 3/8 恒等式死槽，本批 8/8 有存在理由、无数学死槽，设计质量实质提升。四个缺陷：

1. **[一阶] D1/D2 归因洞**：两者共享全库零出现的裸 CVW 内核（G3）且批内无其无门对照——门效应与裸核效应混淆。最近亲孪生（N1eGbEGo，带 VHEX 分母，Sh 1.50/TO 122.8/2Y 1.30）只能给出"门效应+分母效应"的混合估计。
2. **[一阶] D1/D2 壳选择错误**：plain rank 壳在该核上无孪生支撑，而 ts_rank250 壳在可比核上系统占优（+0.12 Sh / +0.59 2Y），直接冲着 LOW_2Y fail 线去。

4. **[记录] brief ops 计数三处差一**：M1a 实算 12（记 11，vec_count 计次问题）、M1b 8（记 9）、D3 3（记 4）。用户 mandate 不限 op，不影响合规，记录在案。

### 替换方案（执行后 GO；保持 8 条 / 2–3 字段 / 无有害算子 / winsorize 命名传参 / 不提交）

- **槽 M1b → CTRL（无门基线）**：`reverse(ts_rank(divide(subtract(news_eod_close, news_eod_vwap), news_eod_vwap), 250))`（4 ops / 2 字段 / 82 字符）。理由：D1/D2（改壳后）的唯一归因基准；裸 CVW 核的首测，其读数同时成为后续所有 vwap-only 工作的锚点。代价是放弃 gate×group 交互读数——该信息可通过 M1a 出结果后的 2 表达式 smoke 补取，不必占主力槽位。若用户判定组层交互优先而保留 M1b，则必须把 D1/D2 的解读预注册为"相对 N1eGbEGo 的混合效应估计"，接受归因模糊。

## §1 DIV 专项审计（数学 / 语义 / 方向）

记号：CVW_R=(EOC−VWAP)/VWAP；DIV(f,s)=ts_rank(CVW_R,f)−ts_rank(CVW_R,s)。

### (a) 稀疏事件场上的 NaN 语义与窗口占据数

**事件锚定已实证（非假设）**：w11f CTRL（CVW_R 核）与 S（DUAL_R 核）书宽均为 289+289=578/1000。若字段逐日填充，任何 CVW_R/DUAL_R 信号的书宽都会是 ~880-960；观测到的 578 证明 EOC（及整个核）在非事件日 NaN，约 42% 宇宙无名值。由此推出**每名每日事件率 p≈0.578**（假设事件在宇宙内近似均匀分布；若实际分布更偏斜，k 的均值不变、方差更大，结论只更强）。

| 快窗 f | 窗内期望观测 k_f（含今日） | P(窗内仅今日=k=1) | 快腿量化粒度 1/k_f | 慢窗 s | k_s | 慢腿粒度 |
|---|---|---|---|---|---|---|
| 5 | 2.9 | **3.2%** | 0.34 | 60 | 34.7 | 0.029 |
| 10 | 5.8 | 0.3% | 0.17 | 120 | 69.4 | 0.014 |
| 20 | 11.6 | 0.03% | 0.086 | 250 | 144.5 | 0.007 |

- **DIV=NaN 的日子的行为**：DIV 非 NaN ⟺ 今日 CVW_R 非 NaN（今日值在两个窗内都在；慢窗必有大量历史观测）。即 DIV 与基信号同支撑集，**书宽保持 ~289/289，不会发生名数崩塌**。整窗 NaN（250 日无事件的名）→ 双腿 NaN → DIV NaN → 落榜，此类名在 news12 宇宙内罕见。
- **k=1 语义未验证（本批最大的平台侧未知）**：BRAIN 的 ts_rank 对"窗内仅 1 个非 NaN 观测"的返回值的三种可能，后果完全不同，须预登记：
  - **分支①返回 1.0**（count(≤)/k 语义）：该名日 f=1.0 机械置顶 → DIV 被推高 → reverse 后**做空**——而 k=1 恰是"最新鲜的事件"，与"新出现的弱势应买入"的故事**符号相反**。G1 受污染 ~3.2% 名日，G2 0.3%，G3 可忽略。
  - **分支②返回 NaN**：该名日落榜，G1 书宽从 289 掉到 ~280（诊断特征：书宽 −3%）。
  - **分支③返回 0.0**（count(<)/k 语义）：DIV 被推低 → 被买入——故事一致但是常数注入，同样扭曲排序。
  判决：无法从外部证实，**G5' 探针（见 §4）就是为分辨此分支而设**——G5' 与 G1 同快窗，其书宽与 Sh 直接暴露分支归属。
- **dflc 退化结论的机制标注**（回应 w11f R2 的"dflc 恒返回 0"诊断）：R2≡S 的观测同样兼容"NaN 传播"分支（dflc(TON) 在非事件日 NaN → less(NaN,2)=NaN → trade_when 给 NaN → 与无门逐位相同）。"门恒真"与"NaN 传播"两种机制产生完全相同的可观测量，实际结论（门在价格字段上空转）不受影响，但机制标签应保留歧义。

### (b) DIV 的值域与分布

- **值域**：[−1, +1]，数学上无退化。**非双峰**，但是"涂抹型离散分布"：慢腿近似连续（粒度 0.007-0.029），快腿离散（粒度 0.086-0.34）→ DIV 的有效档位数 ≈ k_f（3/6/12 档）。截面 rank 后仍有有效排序，但信息量被快腿量化封顶。
- **均值漂移**：E[DIV]=E[f]−0.5≈(k_f+1)/(2k_f)−0.5 = **+0.17 / +0.09 / +0.04**（f=5/10/20）。截面 rank 对平移不变，均值本身无害；有害的是 **k_f 的截面异质性**：事件稀疏的名 k_f 小 → E[DIV] 系统性偏高 → reverse(rank(DIV)) 系统性做空"近期事件少的名"。CVW_R 的事件频数在宇宙内高度偏斜（新闻关注度分布长尾），该混淆项的截面 Spread ~0.1-0.2，与信号本身的 Spread 同量级——**DIV 的排序量中有一部分是"事件密度排序"，不是"新鲜弱势排序"**。这是比 k=1 原子更普遍的结构性瑕疵（影响全部三档，而 k=1 只影响 G1）。
- 结论：DIV 不是恒等信号、不会双峰、不会名数崩塌；它是"带密度混淆的 3-12 档离散二阶信号"。

### (c) 方向推演（符号链）

- 意图链条：CVW_R<0 = 收盘被新闻后卖压压低；快窗分位低（今日是近期最弱之一）且慢窗分位不低（相对全年历史不极端）→ DIV<0 → "弱势是新出现的" → 流动性冲击 → 应买入。
- `reverse(rank(DIV))`：rank 低 → reverse 后权重高 → 买入 DIV 低的名。**符号链完整，方向与故事一致** ✓。
- 机械读法（更诚实）：DIV<0 ⟺ 今日 CVW_R 的近期分位 < 全年分位 ⟺ "CVW_R 分位的负加速度"。经济故事（流动性 vs 知情抛售分解）是对该加速度的一种解释，但全库 417 行没有任何一行测过CVW_R 的二阶特征——这是真新轴，也是无先验轴。
- 两处方向性瑕疵（已在 (a)/(b) 登记）：k=1 原子对 G1 最新鲜名日的符号反转；密度混淆对稀疏事件名的无差别做空（该混淆的符号与经济故事无关，是噪声）。

### (d) 若 CVW_R 逐日填充的反事实

- 证据判定：**不填充**（书宽 578 是硬证据；若填充，DIV 在非事件日变为常数 → 书宽 ~960、TO 坍塌、信号退化为"陈旧填充值的慢去均值"≈ X−ts_mean20 家族 Sh 1.14-1.30）。
- 若假设性填充成立，DIV 的解释将从"事件新鲜度"整体切换为"水平 vs 慢均值"，与 (c) 的加速度故事不同构。**解读规则预登记：以 G1-G3 的书宽判定——≈289/289 = 事件锚定确认，按本报告解释；≈500-960 = 填充语义意外成立，DIV 全部改按去均值家族解读，且 TO 预期需同步下修。**

## §2 修正门专项审计（D 线缺陷的根因确认 + 修复验证）

### (a) 根因诊断确认（brief 的诊断基本正确，一处标签需修正）

- 链条：`reverse(ts_rank(x,250))` = −ts_rank ∈ **[−1, 0]**（reverse=−x 已由 FINAL_REPORT_v2 gate9_S"无 reverse 8/8 负"实证）；`trade_when(cond, X, 0)` 的 else=0 是 X 值域的**极大值** → 门外名（含 ~422 个非事件名，若 else 分支不触碰 x 的 NaN——D1 书宽 732>578 正是该语义的间接证据）以极端值进入截面 → 形成统一伪腿 → L/S 578→732 且 Sh 崩塌 1.54→0.48（D1）、1.54→0.28（D2）。
- **标签修正**：伪腿落在值域极大值一侧（多头侧），不是 brief 所说的"空头腿"；reverse=−x 的实证使 0=max。标签不影响任何结论——伪腿 whichever side 都不是反转 alpha。
- 附带确认：D1 的 TO 25.7% 同样源于伪腿静态性（0 块不换手），**不是门在降换手**——这决定了 §2(c) 的 TO 预测。

### (b) subtract(0.5, ts_rank) 修复的正确性

- 修复后信号 ∈ [−0.5, +0.5]，且 **ts_rank 输出对任意输入分布都近似均匀**（百分位秩的构造性质）→ 截面均值 ≈ 0，分布对称 ✓。else 分支 0 = 分布中心 = 截面中性点。
- **两种平台归一化下的 0 值名行为**：
  - **z-score**：混合总体（门内信号 + 门外 0 块）均值 ≈ 0 → 0 值名 z ≈ 0 → 零权重 → 真正平仓 ✓。
  - **rank 缩放**：0 块位列分布中段（门内负值在下、正值在上），平均 rank ≈ 0.5 → 中心化后 ≈ 0 → 中性 ✓。
- **残留风险登记**：(i) 若平台对 rank 不做中心化直接映射权重，0 块会落在轻微正向权重——仍远比极端值温和；(ii) 门内非事件名（cond 真、信号 NaN）→ NaN 落榜，书宽 ≈ 门内事件名 ~280；(iii) 门外 0 名能否完全零权重取决于归一化细节——**L/S 分支就是为此预注册的**。

### (c) 预注册 L/S 分支与预测修正

| 分支 | L/S 读数 | 判定 | 后续动作 |
|---|---|---|---|
| **门生效+修复确认** | 每侧 **130-170**（总 ~290） | else=0 已中性，门选出门内事件名 | 按干净 IC 解读 G6/G7 |
| 门空转 | ~289/289 | PE/SI 的 rank 语义问题（如仅在事件集上计算） | 结论记为"门不绑定"，换阈值重测 |
| 仍未修好 | 每侧 >250 或总 >650 | 0 在平台归一化下仍非中性 | D 线换修复方案（else 改用门内信号截面均值常数，或改双侧门） |

**TO 预测修正（重要）**：G6/G7 的持仓书 = 门内事件名（~280，事件驱动换手），门外 0 名中性落榜 → 聚合 TO ≈ CTRL 同动力学 ≈ **105-125%**，HIGH_TURNOVER 大概率持续。D1 的 25.7% 是伪腿静态性假象，不可外推。**修正门的价值是 IC 干净读数（Sh 恢复度），不是 TO 豁免**——若用户买 G6/G7 是冲着她降 TO，预期需要下修。

### 槽G5｜reverse(rank(CVW_R)) —— **替换**

- **历史查重（实算）**：正则 `reverse\(rank\(divide\(subtract\(news_eod_close, news_eod_vwap\), news_eod_vwap\)\)\)` 对全部 batch_*.json + 两个 baseline **零匹配**（w11f 前）；最近亲全部带 VHEX 类分母。UXCVW 1.44 的精确形式已查实 = `reverse(rank(multiply(news_max_up_amt, subtract(news_eod_close, news_eod_vwap))))`（batch_gate9_S3 / summary_gate9_S3 实读，Sh 1.44 / 2Y 1.62 / TO 126.8%）——**是交互乘积，不是裸核**，G5 与 UXCVW 不是同一表达式。

## §2 锚点经济学专项（pre / post / main 三组合）

### (a) 三个组合的经济含义

记号：EOC=news_eod_close；VWAP=新闻至收盘时段 VWAP（实读元数据："VWAP from the time of news to the end of the session"）；PVWAP=盘前 VWAP；OVWAP=盘后 VWAP；MVWAP=主时段（全日）VWAP。

- **pre 组合（G8 已测 = H1/H2/H3/H4/H5 的基座）**：`(EOC−VWAP)+(EOC−PVWAP)` = 新闻后盘中压力 + 隔夜/盘前价格发现。经济含义 = **收盘价相对"新闻前均衡点"的全日总位移**，把"可归因于新闻后资金流"与"延续自盘前发现"两部分相加。G8 实测：Ret 6.91%（CVW 单锚）→ **8.25%**（+1.34pp，家族该轴纪录）但 Sh 1.54→1.14（−0.40）——**pre 腿是 Ret 引擎不是 Sh 引擎**。
- **post 组合（H6）**：`(EOC−VWAP)+(EOC−OVWAP)` = 新闻后压力 + 盘后出清偏离。经济含义 = **位移在延时交易中的延续性**——若新闻日跌势在盘后继续，EOC−OVWAP 同向放大，双锚和度量"被确认的压力"。post 单锚的实测画像（e76PGzZg Sh 1.27/Ret 7.66%/**2Y 2.08**；9qE3k7mr Sh 1.40/Ret 7.60%/**2Y 2.35**）表明它是**家族最强 2Y 引擎**（对标 CPV 2.08-2.14、家族 2Y 纪录 MP0Eragz 2.40）。
- **main 组合（H7）**：`(EOC−VWAP)+(EOC−MVWAP)` = 新闻后压力 + 全日均衡偏离。**关键结构事实：新闻至收盘窗 ⊂ 主时段，MVWAP 腿与 VWAP 腿共享大部分信息内容**（新闻时刻越晚重叠越大）。双锚和 ≈ 2× 盘中压力 + 盘前漂移——经济含义最弱：本质是已知 vwap 信号的 2:1 再加权，掺入一份被稀释的盘前漂移（而盘前漂移 H4/H5 测得更干净）。**先验：H7 ≈ CTRL 与 G8 之间的内插点，信息增量最低。**

### (b) 哪个组合最可能提升 Sh 而非只提升 Ret？

**三个都不最可能；若必须排序：H7 > H6 > pre（已测）。** 混合算术：blend 的 Sh 被拉向较弱腿的 IC——G8 实证 pre 组合 −0.40 Sh。H7 的第二腿与第一腿相关性最高（同会话包含关系），稀释最少（预期 −0.1~−0.25）；H6 的第二腿独立但更弱（1.27 vs 1.54），稀释居中（−0.2~−0.4）；pre 组合稀释最大（已实测 −0.40）。**但注意：三者的 Sh 上限都低于 ts_rank250 壳的单锚修复（H2 ≈ 1.22-1.32）——"加锚点"这条路在 Sh 维度上是被 G8 证伪的方向，它的价值在 Ret/2Y 维度。**

### (c) H6/H7 的槽位价值审判

- **H6 不是已知量**：post_vwap 表达式层 12 次使用中，**sum 形式零先例**；唯一的 post×vwap 组合是 product 形式 YPxOYg9q（`reverse(rank(multiply(EOC−post, EOC−vwap)))` → Sh **0.17** / 2Y −0.05 / sub −0.10，六 fail 全灭）。H6 回答一个真问题："sum 形式是否逃逸 product 形式的毒性？" 且 post 腿是家族 2Y 引擎，若 blend 后 2Y ≥ 2.20 则是 2Y 候选。**保留**——但 CW fail 先验 75-85% 是全批最高（post 锚 10/12），解读必须按 CW fail 为默认结局预登记。
- **H7 最接近已知量**：MVWAP 零使用是真，但经济冗余性先验强（腿间信息包含关系）。它的诚实定位是"blend 轴的 CW 安全对照"（常规锚 + 双腿族 0/17 CW fail），不是 Sh/Ret 候选。**第一砍单对象**——若批次需要腾挪槽位（如给 dflc(VHEX)≤2 门版的 DA_PRE 或 H8 的语义修复版），砍它。

## §3 H8 语义审计（量能确认乘子）

**表达式**：`reverse(rank(multiply(subtract(EOC, VWAP), add(abs(news_vol_stddev), 1))))`。

### (a) 经济学是否成立：半个成立

- **支撑家族故事的一半**：战役主叙事 = 新闻日过度反应 + 做市流动性补偿。量能异常放大价格压力 = 流动性需求冲击更深 = 反转应更强。乘子 `(1+|z|)` 把权重集中到"高量能确认的压力"名上，与故事同向。
- **竞争故事（未排除的）**：高量能 + 收盘破 VWAP = 知情机构派发（informed flow）——该情形**不**反转。哪个故事主导是实证问题，先验 50/50。
- **最近的实证先例中性**：UXCVW = `multiply(news_max_up_amt, subtract(EOC,VWAP))`（振幅确认乘子，非对称版）→ Sh 1.44 / 2Y 1.62 / CW ok / L/S 268/270——与裸 CVW rank 壳（内插 ~1.44-1.50）基本持平。即"确认乘子"架构有一次中性读数，不帮忙也不致命。

### (b) 乘子量纲与符号风险

- **符号安全**：`(1+|z|) ∈ [1, ~11+]` 恒正 ⟹ 乘积符号 = (EOC−VWAP) 符号，无符号反转。reverse 后多空两侧对称放大。✓
- **量纲安全**：(EOC−VWAP) 为价格单位，乘子无量纲，乘积仍为价格单位；截面 rank 无单位问题。✓
- **真实缺陷是 abs() 的语义混淆（预注册分支）**：vol_stddev 是 30 日量能 z-score，`abs(z)` 大 = **双向极端**——成交量暴涨（z≫1，事件确认，有经济含义）**或**成交量枯竭（z≪−1，无确认含义）。枯竭名的"压力×大乘子"把弱流动性阴跌名放大至 ~10×，与故事无关地注入排序量。**这不是参数问题是构造缺陷。**
- **CW 风险**：乘积极端 = 最大 |压力| × 最大 |z| = 最新闻化的名，正是 CW 集中名的候选池；UXCVW 先例 CW ok 是好消息，但 UXCVW 的乘子有界（振幅字段），|z| 无上界（新闻日可 10-30）。CW fail 先验 25-40%。
- **支撑集**：vol_stddev cov 0.9672 逐日填充，(EOC−VWAP) 事件锚定 ⟹ NaN 传播保支撑 = 事件日，L/S ≈ 289/289，不会名数崩塌。✓

### (c) 预注册解读分支

| 读数 | 判定 | 后续动作 |
|---|---|---|
| Sh ≥ 1.40 | 量能确认是真实 IC 放大器，"流动性需求"故事获全战役最强支持 | 确认架构升级：试非 abs 版（`multiply(EOC−VWAP, add(vol_z,1))` 或 greater 门）精修 |
| Sh 0.95-1.35 且 L/S≈289 | abs 混淆分支：枯竭名污染，确认效应被稀释一半 | 补测 `trade_when(greater(vol_stddev,0), ·, 0)` 或乘子改 z 非 abs（各 +2~3 ops，仍合规） |
| Sh ≤ 0.70 | 量能确认的压力是知情流（故事 B），确认架构死亡 | 不再投入乘子类槽位；UXCVW 的 1.44 重解释为"上行振幅"特例 |

## §5 批次整体判决

### 信息结构评估

覆盖轴：CW 修复四机理同台（H1 截尾 / H2 有界+时序归一 / H3 支撑集加宽 / H5 分母归一）/ pre 锚强度隔离（H4）/ 锚点 blend 三组合（H6 post、H7 main；pre 组合已由 G8 覆盖）/ 新机制确认乘子（H8）。对比前三轮：无恒等式死槽、无合规死槽、无重复、每个 CW 修复在 TON 腿上都有已测孪生作差分基准（xA1ZKGzg / KPm1Kz8k / WjLZbE7N / 9qE3k7mr-on-post）——**归因结构是四轮最干净的**。核心风险不在设计在先验：G-B 决定 Sh 1.58 不可达，G-A 决定四个 CW 修复中只有一个（H3）的先验超过 75%。

### 判决：**GO（有条件）**

- **八条全部保留**：每条回答一个不同问题，无砍单的必要性（ops/字段/字符全合规、查重零匹配）。
- **若必须砍一个：H7**（信息增量最低，MVWAP 腿与 vwap 腿的信息包含关系使其读数可由 CTRL 与 G8 内插；其 CW 安全对照职能可被 H3 部分替代）。
- **预注册三项**：(1) G8 CW fail 的两种机理假设及 H1/H2/H3/H5 的 L/S 分支判据（§1b）；(2) H8 的 abs 混淆分支及后续修复形式（§3c）；(3) H6 按 CW fail 为默认结局解读（post 锚 10/12 先例），Sh 读数不做 CW 条件化解释。
- **不替换**：H1/H2/H3/H4/H5/H6/H8 各有不可替代的问句。

### 预期结局与成功画像

0/8 通过 mandate（G1 Fit 墙 + G2 CLUSTER_TEST 恒警 + TO 墙，四轮不变）。本批真实产出 = 三张判决性读数：

1. **CW 修复方法判决**（批次头条）：若 H3 CW 转绿（先验 75-80%）而 H1/H2/H5 仍 fail（先验 50-55/35-50/50-65%）→ **行业聚集驱动确认，CW 解法 = 支撑集加宽（bf2）或名集过滤（dflc 门），数值分布修复全部判死**——这直接决定 pre 轴后续所有构造的壳选择。反之若 H1/H2 有任一转绿 → 截尾/有界化有效，CW 解法可低成本推广。
2. **pre 锚点轴强度隔离**（H4）：pre 腿单独 Sh ≥ 1.40 → blend 稀释确认，锚点轴转单锚；≤ 1.00 → 协同确认，blend 正确。
3. **Ret 纪录可能性**：H1 Ret 8.0-8.9%（P(>8.47%) ≈ 25-30%，全批最高）、H4 7.0-8.5%（≈20-25%）、H6 7.5-8.8%（≈20%）。**Sh > 1.56：无槽有现实路径**（需 +0.44 vs 历史单构造最大 +0.13；最高预测 H5/H7 上限 1.45，P < 5%）。

最优可行剖面：H3 若 CW 转绿 → G8 的 4 fails 降到 3（Sh/Fit/TO），且是家族 TO 曲线新端点（85-105% 区）；H2 若 2Y ≥ 2.20 → 3-4 fails 但是 pre 轴 2Y 候选；H1 若 CW 转绿 → 3 fails + Ret 8.5%+。**把预期设在这里，批次就是成功的——任何以"Sh 1.58/2-fail"为成功标准的解读都会把一批好数据误判为失败。**

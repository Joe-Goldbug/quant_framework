### 槽2/3/4｜尾部选择 90 / 95 / 80 —— 设计性死亡，三槽全砍

**四段链之问的回答（brief 点名必审）**：不需要讨论机制，因为**表达式是恒等式**。硬推理：

1. `reverse(x) = −x`（实证：`FINAL_REPORT_v2.md` gate9_S"无 reverse 8/8 负"——同结构去掉 reverse 后 8/8 为负；wave9_S2 的 3qjOGPzz 带 reverse 为 +1.58）。
2. `ts_rank(·,250)` 输出 ∈ [0,1]（brief 自述"近似均匀分布"+ BRAIN 百分位语义）。
3. ⟹ **S ∈ [−1, 0]，恒 ≤ 0**。
4. `greater(S, 0.9)`：S ≤ 0 < 0.9 ⟹ **恒假**。`less(S, 0.1)`：S ≤ 0 < 0.1 ⟹ **恒真**。
5. ⟹ 槽2 = trade_when(恒假, S, trade_when(恒真, S, 0.5)) ≡ **S**（逐点恒等，非近似）。槽3/4 同理——0.95/0.05 与 0.8/0.2 全部落在 S 的值域之外（死区）。

本地纯逻辑数值验证（非回测，合成序列）：greater(S,0.9) 为真比例 0.0000；less(S,0.1) 为真比例 1.0000；槽2 输出与 S 逐点相同 = True。

**残留分支（NaN 单元格，约占宇宙 42%）**：BRAIN 对 NaN 参与比较的语义有两种可能，两种都无救：
- **分支A（NaN 比较返回 false）**：NaN 格落入最内层 `0.5` → 向截面注入一个约 42% 名字组成的静态多头腿（z 标准化后约 +2σ）→ alpha 畸变为"多头：无新闻多数 + 空头：极端压力少数"。预测 Sh 0.7–1.3、TO 90–115%、Ret 9–11%（IS 期净偏多摄入贝塔 drift）、Fit 0.3–0.5、CW ok、sub 0.5–1.0。死法：LOW_SHARPE + LOW_FITNESS + HIGH_TURNOVER。
- **分支B（NaN 比较传播 NaN）**：恒等于槽1 → Sh 1.56 / TO 119.8% / 3 fails 复刻。

**关于"尾部选择是否有经济含义"的直接回答**：作者意图的版本（|S|>0.9）选的**不是**恒定比例随机抽样，而是每股自身 250 日压力的历史极端（ts_rank 是个股自身历史分位）——"极端过度冲击 → 最强反转"是有经济含义的状态条件，这一点作者的直觉是对的。但：(a) 它没被写对（符号死在 reverse 上）；(b) 全战役状态门证据表明这类门要么不降 TO（dflc 新鲜门：TO 不升、Sh +0.04~0.13），要么超比例杀 Sh（VHEX>2 硬门：TO 36% 但 Sh 0.86）；(c) 即使写对也过不了 ops 限额（见下）。

**合规**：**28 ops（超 mandate 上限 2.8×）** / 3 字段 ✓ / ~575 字符 ✓ / 无有害算子。根因：FASTEXPR 无变量绑定，S（6 ops）在表达式里被展开 4 次。**任何"信号出现 ≥2 次"的门设计都 ≥13 ops——尾部选择在该 mandate 下不可表达。**

**预测向量**：分支A：Sh 0.7–1.3 / TO 90–115% / Ret 9–11% / 2Y 1.0–1.8 / CW ok；分支B：同槽1。主要 fail：LOW_SHARPE + LOW_FITNESS + HIGH_TURNOVER。置信度：分支判定 0.5:5，无一是活路。
**判决**：**三槽全砍。** 数学正确形式为 `trade_when(greater(abs(S),0.9), S, 0)`（15 ops，见 §4 R2alt），需 ops 放宽；完全合规的替代门见 R2。

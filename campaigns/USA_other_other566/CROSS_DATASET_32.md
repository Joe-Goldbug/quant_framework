## 一、为什么"大费周章"反而不如种子（量化回答）

### 1. 种子已经坐在它所在信号族的 Fitness 最优点上

243 个已解析槽位的最终分布：

| 维度 | 优于种子的槽位数 | 全库最好 |
|---|---|---|
| Sharpe > 1.27 | 24 / 243 | 1.73（换手 73.1%） |
| Margin > 4.37 | 59 / 243 | 13.1（波次 32） |
| Turnover < 13.93% | 123 / 243 | 1.01% |
| **Fitness > 0.59** | **9 / 243** | **0.63（+7%）** |

也就是说：单项指标很容易赢种子，**但 Fitness 几乎无解**——243 次尝试只有 9 次超过，上限比种子高 7%。

原因是一个代数恒等式。设 R=Returns，TO=Turnover，Mgn=20·R/TO，`Fitness = |Sharpe|·√(|R|/max(TO, 0.125))`：

- TO ≥ 12.5% 时：`Fitness = Sharpe·√(R/TO) = Sharpe·√(Mgn_bps/20)`，即 **`Fitness = Sharpe·√(Mgn_bps/20)`**
- 于是 `Sharpe²·Mgn_bps ≥ 22.05` 是通关条件，而 `Sharpe²·Mgn_bps` 是本信号族的一个**可测常数**。243 个槽位实测最大值 ≈ **7.9**，故 `Fitness ≤ √(7.9/20) = 0.63`——与实测上限 0.63 完全一致。
- TO < 12.5% 时：`Fitness = Sharpe·√(R/0.125) = Sharpe·√(TO·Mgn_bps/2.5)`，Fitness 不再随 Margin 单调，而是只随 Returns 走（见下面第 3 点）。

这个恒等式说明：**Sharpe 与 Margin 在此信号族内是可互相替代的，不是两个可以分别优化的目标。** 任务书里每一条"根因修复"都只盯着其中一端，所以每一轮都只是沿着同一条前沿滑动，从来没有离开前沿——这就是"做了 8 轮却始终不如种子"的根本原因。

### 2. 三条被实测证伪的"根因修复"（不是没试，是试出了反效果）

| 任务书指令 | 实测结果 | 波次 |
|---|---|---|
| 用 `ts_zscore(x,40)` / `ts_ir(x,30)` 提取"时序预期差" | Sharpe **1.27 → 0.22**。`ts_zscore` 减掉的正是预测水平本身，而本数据集的 alpha 全在这个水平里 | 25 |
| `target_tvr` 降到 0.035~0.055 以抬 Margin | 换手从 13.93% 砍到 3.86%，**Margin 4.37 → 4.67 → 3.86**。`ts_target_tvr_decay` 靠等比缩小仓位达标，Returns 同步缩小，R/TO 不变 | 26 |
| `signed_power` 幂次 1.3 / 1.5 / 1.8 | Sharpe 0.92 / 0.93 / 0.93 —— **整条维度是死的** | 29 |
| `hump` 不交易带 | Sharpe 0.14（band=0.015）/ 0.17（band=0.01）—— 在 5% 换手的书上，band 把有效仓位也一起削掉了 | 29 / 32 |

### 3. 换手地板效应

Fitness 的分母在 TO < 12.5% 时**锁定为 0.125**。这意味着一旦把换手压到 12.5% 以下，**再压换手对 Fitness 毫无帮助**，唯一的出路是提高 Returns——而 Returns 恰恰就是种子的换手买来的东西。所以"降换手 + 提 Margin"这条路在 12.5% 以下自我抵消。

### 4. 结论

种子那条 3 算子表达式（`group_zscore(ts_target_tvr_decay(multiply(ret, prob_5), 0.12), industry)`）恰好落在该数据集的**换手-信号最优交换点**上。我构造的 5~11 算子版本每一个都多引入了至少一个约束，每个约束都损失信息。**"更精巧"在这里等于"更差"。**

## 二、波次 32：跨数据集（2~3 字段，op 5~7，全部有经济学假设）

### 假设

- **A（慢速腿 / 估值自锚）** `diff_current_vs_hist_price_ratio_earnings` —— 当前远期 P/E 减自身过去 12 个月中位数。估值倍数均值回复（Campbell & Shiller 1988；Asness-Moskowitz-Pedersen 2013）。自归一化 ⇒ 剔除行业与成长阶段差异；锚是滚动 12 个月中位数 ⇒ 换手天然极低。
- **B（慢速腿 / 修正漂移）** `highest_estimate_change_quarterly_eps_30d_long` —— 30 天季度 EPS 预估变动率。PEAD / 修正漂移（Bernard & Thomas 1989；Chan-Jegadeesh-Lakonishok 1996）。分析师预期粘性 ⇒ 修正连续同向 ⇒ 价格渐进吸收。
- **C（快腿 / 图表动能，仅作倾斜）** `oth566_r20marsi_ret` —— 视觉显著形态吸引注意力驱动资金流（Barber & Odean 2008）。权重刻意压到 0.2~0.5，只贡献择时不贡献换手。

### 三个明确结论

**1. Margin 门禁被真正打通了（这是唯一实质进展）。**
`VR_w30_t03` 的 **Margin 13.12 bps**，是 256 槽的历史最高，是种子的 **3.0 倍**，也是唯一一次让"AEGIS 的 USA Margin ≥10bps"与"接近 15bps"同时出现在一个 Sharpe 为正的 alpha 上。这证实了我此前的判断：**Margin 卡死不是参数问题，而是信息源问题**——把慢速基本面锚放进组合，R/TO 立刻从 0.218 升到 0.66~0.82。

**2. 但 Sharpe 在同一处崩了，而且与数据源无关。**
全库换手 ≤ 7.33%（Margin≥15 的必要条件）的 **17 个槽位，最高 Sharpe = 0.66**，而本轮跨数据集的最好在 0.65。换信息源**完全没有改变**这个水平。

**3. 修正漂移字段是废的。**
`R_w30` Sharpe 0.23、Margin 2.44，且 `VR_w30`(0.65) 与 `V_w30`(0.60) 几乎无差 —— 说明这条腿贡献接近零，`highest_estimate_change_quarterly_eps_30d_long` 在 TOP1000 上无预测力。

## 三、门禁可行性代数（当前证据下的精确缺口）

三个硬门禁联立（Margin 与 Fitness 的公式都是平台定义）：

```
Margin = 20·R/TO ≥ 15  且  R ≥ 5.5%
   ⟹ TO ≤ 7.33%

TO < 12.5% 时 Fitness = Sharpe·√(R/0.125) ≥ 1.05
   ⟹ Sharpe ≥ 1.583；且 R=5.5%、Sh=1.58 ⟹ 年化波动 ≤ 3.47%
```

即通关点唯一：**Sharpe ≈ 1.6、Returns 5.5%、Turnover 7.3%、波动 3.5%、MaxDD ≤ 2.8%**。
（顺带说明门禁之间**不自相矛盾**，只是要求一个 IR 1.6 的低波市场中性账本。）

对照组：

| | Sharpe | Returns | Turnover | Margin | 波动 |
|---|---|---|---|---|---|
| 通关所需 | ≥1.58 | 5.5% | 7.3% | 15 | 3.5% |
| 全库在 TO≤7.33% 的最好 | 0.66 | 2.76% | 5.30% | 10.4 | 4.2% |
| 种子 | 1.27 | 3.04% | 13.93% | 4.37 | 2.4% |

**缺口：在合规换手区，Sharpe 需要 2.4 倍。** 243 槽加上本轮 8 槽，全库最高 Sharpe 是 1.73，而它出现在 73.1% 换手处。

## 四、判定

- 任务书的五条门禁在 USA/D1/TOP1000 + `oth566` 这一族信息源上**不可同时达成**，本轮（含跨数据集）再次确认，累计 256 槽 0 通过。
- 本轮唯一可交付资产：`e756LVRO`（VR_w30_t05，Sh 0.65 / Mgn **10.36** / TO 6.36% / Cluster 0.47）与 `A1VQkrdd`（VR_w30_t03，Sh 0.53 / Mgn **13.12** / TO 4.09% / Cluster 0.33）。二者的 **Cluster 相关性只有 0.33~0.47（种子是 0.95~1.20）**，这是同族 alpha 里罕见的低拥挤度；但 Sharpe 与 DD（10.3%）都远劣于种子，不建议作为替代提交。
- 要真正通关，必须换**alpha 家族**（慢速、高 IR、低波的截面信号），而不是继续在 `oth566` 的表达式上做变换。
